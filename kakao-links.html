카톡 보내기용 글 모음 (직원용)

상담하신 병에 맞는 글 옆 [복사]를 누르면 안내 문장과 글 주소가 함께 복사됩니다. 카카오톡 채널 1:1 채팅이나 솔라피 알림톡에 붙여 넣으세요. 맨 위 글이 그 병의 대표 글입니다. 이 페이지는 검색에 나오지 않습니다.

목·어깨(상지·손 포함)

  1. **대표 글**: 어깨가 굳어 팔이 올라가지 않는 오십견(유착성 관절낭염)은 어떻게 살피나요?
  2. 거북목과 목 뒤 뻐근함은 한의원에서 어떻게 살피나요?
  3. 어깨에 담이 걸려 쇄골·목 주변까지 당길 때 첫 며칠은 어떻게 하나요?
  4. 어깨와 등이 늘 뭉쳐 있고 담이 자주 걸리는 근막통증증후군은 어떻게 살피나요?
  5. 목에서 팔로 저림이 내려올 때(목디스크 의심)는 어떤 점을 먼저 확인하나요?
  6. 새벽에 손이 저려 깨는 손목터널증후군은 어떻게 살피나요?

허리 통증

  1. **대표 글**: 몇 달·몇 년째 좋아졌다 나빠졌다를 반복하는 만성 요통은 어떻게 살피나요?
  2. 허리를 삐끗해 움직이기 힘든 급성 요추 염좌는 첫 며칠 어떻게 살피나요?
  3. 아침에 일어나면 허리가 뻣뻣한 것은 왜 그런가요?
  4. 허리디스크 진단을 받았는데 수술 없이 침·추나·약침으로 관리해도 될까요?
  5. 걸으면 다리가 저려 자꾸 쉬어야 하는 척추관 협착증은 어떻게 살피나요?

다이어트·체중

  2. 다이어트를 할 때마다 요요가 오고 정체기에서 멈춰 버릴 때는 무엇을 살피나요?
  3. 비만이라는 말을 들었을 때 체중보다 먼저 무엇을 살피나요?
  4. 갱년기 무렵 먹는 양은 그대로인데 뱃살과 체중이 늘어날 때는 무엇을 살피나요?
  5. 출산 뒤 몸무게가 잘 빠지지 않을 때, 산후 체중 관리는 언제부터 어떻게 하나요?

  4. 족저근막염 통증에 체외충격파는 어떻게 사용하나요?
  5. 어르신이 계단에서 발목을 헛디뎠을 때, 붓지 않았다면 괜찮은 걸까요?

무릎

  2. 계단을 내려갈 때 무릎이 아프면 한의원에서는 무엇을 먼저 묻나요?
  3. 무릎 안쪽 아래가 아픈 거위발건염은 무릎 관절염과 어떻게 다르고 어떻게 살피나요?
  4. 무릎 인공관절 수술을 받은 뒤 재활 기간에는 무엇을 살피고 어떻게 지내나요?
  5. 상도동 언덕길과 계단을 매일 오르내릴 때 무릎은 어떻게 챙기나요?

  2. 당뇨 전단계·공복혈당장애라는 말을 들었을 때 무엇부터 살피나요?
  3. 콜레스테롤과 중성지방 수치가 높게 나오면 생활에서 무엇부터 보나요?
  4. 건강검진에서 지방간이라는 말을 들었을 때 생활에서 무엇을 점검하나요?
  5. 고혈압 진단을 받았거나 경계라는 말을 들었다면 생활에서 무엇부터 살피나요?

  4. 자주 체한다는 느낌, 식체나 담적이라는 말은 무엇을 뜻하고 어떻게 살피나요?
  5. 배가 자주 아프고 설사·변비가 반복되는 과민성 장 증후군은 어떻게 살피나요?
