# 네이버 블로그 프리미엄 원고 지침 (2026-11-27, 원장님 전권 위임)

원장님 목표: 블로그 4개에 "네이버 저품질에 안 걸리는 선에서, 최대한 길고 고품질 글을, 가능한 빨리 많이". 사람들이 좋아하고 끝까지 읽을 글. 대행사에 한 편 10만 원 내고 맡긴 수준(프리미엄 플러스).

## 견본 (반드시 먼저 읽기)
- 원고: posts/hcning20-five-basics.md
- 그림 설계: cards-premium/hcning20-five-basics.json → `node premium.mjs <slug>` 로 images/<slug>/NN.png(사진 카드는 .jpg) 생성
- 카드 종류와 필드: premium.mjs 를 읽어 확인(coverPhoto, photo, chapter, five, check, steps, warn, compare, selfcheck, quote, note, info)

## 분량·구성
- 본문 6,000~8,000자(공백 포함), 그림 18~25장. 원고의 `![설명](NN.png 또는 NN.jpg)` 줄 수 = cards JSON 카드 수, 순서도 같게(01부터).
- 사진 카드는 ~/hanui/images/real/ 의 실제 사진만(파일 이름 그대로, 예 "room-consult1.jpg"). **쓰기 전에 Read 로 사진을 직접 보고 설명이 사진 내용과 맞는지 확인.** 한 글에 사진 6~9장, 나머지는 설명 카드.
- 다 만든 뒤 images/<slug>/ 의 그림을 전부 Read 로 열어 글자 넘침·겹침·빈 카드가 없는지 눈으로 확인하고 고친다.
- 제목은 검색되는 말(증상·상황 + 지역은 자연스럽게 1회)로, 낚시·과장 없이.
- 소제목 5~8개, 짧은 문단, 체크리스트·단계·자가 점검처럼 저장하고 싶은 내용. 같은 말 반복·기계 말투·"~입니다. ~입니다." 연속 금지. 글마다 문장 틀을 다르게.
- 태그 10~15개(front matter tags).
