# 글 올리는 방법 (한방가이드)

1. `content/posts/` 에 `.md` 파일 하나를 만듭니다. 기존 글을 복사해서 고치면 가장 쉽습니다.
2. 맨 위 머리말을 채웁니다.

```
---
title: 질문 형태의 제목 (예: 계단을 내려갈 때 무릎이 아프면 …?)
category: pain            # pain / metabolic / first-visit  (site.json 에서 추가 가능)
slug: knee-stairs-down    # 영문 소문자와 하이픈, 글마다 달라야 함
date: 2026-11-22
updated: 2026-11-22       # 고칠 때마다 날짜 갱신
summary: 80자 안팎의 한 줄 답변 (글 맨 위 '한 줄 답변'과 검색 설명으로 쓰임)
draft: true               # 이 줄이 있으면 발행하지 않음 (발행하려면 삭제)
---
```

3. 본문: `## 소제목`, 문단, `- 목록`, `**굵게**`, `[링크](주소)`.
4. 자주 묻는 질문은 이 형식으로 (글 아래쪽에 한 번):

```
::: faq
Q: 질문
A: 답
:::
```

5. `python build.py` 를 실행하면 글 페이지, 목록, 홈 최신 글, `llms.txt` 가 갱신됩니다.

## 발행 전 확인 (의료광고)
- 치료 효과를 약속하는 표현, 수치 개선 사례, 환자 후기, 전후 사진은 쓰지 않습니다.
- 질환 이름은 쓰되 "치료됩니다" 대신 "살핍니다 / 관리를 돕습니다"로 씁니다.
- 약 복용 중인 분께는 "임의로 중단하지 마세요"를 넣습니다.
- 원장님이 직접 읽고 감수한 글만 발행합니다. (글에 "감수 이종호 대표원장"이 표시됩니다.)

## 도메인이 정해지면
- `site.json` 의 `base_url` 에 주소를 넣고 `python build.py` 를 다시 실행하면 `canonical`, `sitemap.xml` 이 만들어집니다.
- `site.json` 의 `reviewer.license` 에 한의사 면허번호를 넣으면 글마다 표시됩니다. (지금은 비어 있어 표시하지 않음)
