# 맥미니 Ollama(로컬 AI)에게 넘길 일 — 토큰 아끼기 (원장님 지시 2026-11-25)

원칙: **판단·원장님 목소리·의료광고 최종 판단은 Claude, 반복·초안·정리는 Ollama, 규칙으로 되는 일은 그냥 파이썬(AI 안 씀).**
Ollama 결과는 그대로 배포하지 않는다. 반드시 `python3 tools/ad_check.py` (금지어 검사) + 빌드 점검을 통과해야 하고, 사람에게 보이는 글은 Claude가 마지막에 한 번 훑는다(짧게).

## 0. 준비 (한 번)
- `ollama list` 로 설치된 모델 확인. 없으면 맥미니 메모리에 맞게 설치:
  - 메모리 16GB: `ollama pull qwen2.5:14b` (한국어 무난) 또는 `gemma3:12b`
  - 메모리 32GB 이상: `ollama pull qwen2.5:32b`
- `tools/ollama_run.py` 를 만든다: 프롬프트 파일/문자열을 받아 `http://localhost:11434/api/generate` 로 보내고 결과를 파일로 저장. 온도 0.3, 한국어로만 답하게 시스템 문구 고정, 타임아웃 10분, 실패하면 빈 결과 + 기록(이때만 Claude가 대신 함).

## 1. 아예 AI가 필요 없는 일 (파이썬으로만)
빌드·링크 점검·최종 점검·사이트 진단(site_audit)·IndexNow·작업현황 파일·WebP 변환·사진 크기 줄이기·drip 순서 끼우기·사이트맵. → Claude 호출 없이 셸 스크립트로 돌린다.

## 2. Ollama에게 넘길 일
| 일 | Ollama가 하는 것 | 검사 |
|---|---|---|
| **안내 그림(SVG) 글귀 뽑기** | 글 본문에서 '여쭙는 것 4개·해 볼 것 4개·확인 신호 3개'를 22자 이하로 요약해 JSON으로 | 글에 없는 말이 있으면 버림(원문 단어 대조), 금지어 검사 → 그림은 파이썬 템플릿이 그림 |
| **네이버 블로그용 고쳐 쓰기 초안** | 홈페이지 글을 블로그 말투로 바꿔 쓰기(같은 문장 50% 이상 겹치지 않게) | 금지어 검사, 임시저장만(발행은 원장님) |
| **사진 alt 문구·메타 설명(description)** | 50~120자 요약 | 길이·금지어 |
| **글 태그·관련 글 추천** | 글마다 키워드 5개 | 기존 분류와 맞는지 |
| **맞춤법·띄어쓰기 1차 교정** | 고칠 곳 목록만 | 사실·숫자는 건드리지 않음 |
| **자주 묻는 질문 초안** | 본문에서 Q&A 3개 초안 | Claude가 확인 후 반영 |
| **운영일지 숫자 정리** | 진단 점수·발행 수를 표로 | — |

## 3. Claude가 계속 할 일 (넘기지 않음)
- 원장님 목소리 글(티로·지피티·원고), 진맥·철학 페이지, 새 글 본문 작성과 보강(B5)
- 의료광고·개인정보·사실 판단, 원장님께 드리는 제안(F 자체평가)
- 디자인·build.py 코드 수정, 사진 고르기(환자정보 확인)

## 4. 운영 방법
- `tools/auto_prompt.md` 의 C·D(안내 그림)와 네이버 블로그 초안은 **먼저 Ollama로 시도**하고, Claude는 결과 검사와 실패분만 처리한다.
- Ollama가 3번 연속 실패하거나 결과 품질이 낮으면(금지어·사실 불일치가 잦으면) 그 일은 다시 Claude로 돌리고 운영일지에 적는다.
- 매일 저녁 자체평가에 "오늘 Ollama가 한 일 수 / Claude가 한 일 수"를 한 줄 적는다.
