## 2. 지식 카드

> 형식: 자주 묻는 질문(Q) → 설명 요지 → 원장의 언어(상태 표시) → 배치 위치

### PART A. 정체성·진료 철학 → [원장 소개·철학]

**01. 병이 아니라 사람을 바라보는 진료** (최우선)
- Q: 허리가 아픈데 왜 잠이나 소화까지 묻나요? / 아픈 곳에 침만 맞으면 안 되나요? / 같은 증상인데 왜 사람마다 치료가 다른가요?
- 요지: 통증은 몸이 보내는 신호 중 하나 → 구조적 문제와 함께 수면·소화·피로·생활 습관을 살핌 → 질환명보다 환자 개인 상태로 치료 방향을 정함
- 원장의 언어 ✅ 원문: "병만 바라보는 의사가 아니라, 병으로 고통받는 사람을 바라보는 의사가 되겠습니다."

**02. 건강한 리듬, 행복한 기억** (최우선)
- Q: '좋은꿈'이라는 이름의 의미는? / 한의원은 건강을 어떻게 정의하나요?
- 요지: 건강은 통증이 없는 상태만이 아님 → 잘 자고, 잘 소화하고, 잘 배설하고, 잘 움직이는 상태 → 치료 중 이런 생활 상태의 변화도 관찰
- 원장의 언어 ✅ 슬로건: "건강한 리듬, 행복한 기억."

**03. 진료실을 지키는 등대** (최우선, 원장 소개 마지막 문장)
- Q: 대표원장님은 어떤 마음으로 진료하시나요?
- 요지: 충분히 이야기할 수 있는 진료실 → 치료의 가능성과 한계를 설명 → 한 번의 방문 이후 변화까지 관심
- 원장의 언어 ✅ 원문: "어두운 바다를 늘 지키고 있는 등대처럼, 진료실을 지키며 환자분들의 길을 비추겠습니다."

**04. 지난 진료를 기억하는 한의원** (높음)
- Q: 방문할 때마다 같은 이야기를 다시 해야 하나요? / 지난 치료와 오늘 치료가 이어지나요?
- 요지: 재진 때 지난번 가장 불편했던 증상을 다시 확인 → 위치·강도·움직임·수면 변화 평가 → 치료를 재평가하고 기계적 반복은 피함
- 원장의 언어 🟡 초안(홈페이지 기존 문구): "지난번에 무엇이 가장 불편하셨는지, 오늘은 얼마나 편해지셨는지 이어서 묻겠습니다."

**05. 모든 치료의 시작과 끝, 진맥** (높음)
- Q: 진맥으로 무엇을 알 수 있나요? / 통증 환자도 진맥이 필요한가요?
- 요지: 맥·설진·문진·신체 소견을 종합 → 피로·수면·소화 등 전신 상태 평가의 참고 → 진맥만으로 모든 질환을 판별하지 않고 필요하면 다른 검사를 병행
- 원장의 언어 ✅ 원문: "모든 치료의 시작과 끝에 진맥이 있어야 한다."

**43. 몸따삶잘: 체온·소화·수면·대소변** (뜻풀이 확정 필요)
- 네 가지 관찰 축: 체온(추위·더위, 손발 온도) / 소화(식욕, 식후 편안함) / 수면(잠들기, 잠의 연속성) / 대소변
- 원장의 언어 ✅ 키워드: "몸따삶잘"
- 메모: 홈페이지의 독자 콘텐츠로 키울 만합니다(자가 체크 위젯 등).

**46. 끊임없이 공부하는 한의사** (높음)
- 요지: 사암침·한약 이론 재학습, 근골격계 초음파·신체 진찰 병행, 새로운 이론은 근거 수준을 따져 신중하게 적용
- 원장의 언어 ⚪ 재구성: "오래 진료했다는 이유로 공부를 멈추지 않겠습니다."
- 함께 넣을 프로필 사실: 동작구 어르신 치매예방·노인 치매관리사업·한의약 난임치료 지원사업 지정 한의사, 식약처장 위촉 한약 관능검사 전문가(2026.08~2028.08), 학교 교의(은로초·중대부중·숭의여중), 방송 고정 패널(2021 MBN 건강한의사, 2022 MBN 한방이 답이다, 2023 EBC 여의보감), 2013년 개원

### PART B. 수면·자율신경 → [진료과목: 불면·수면 건강] + [칼럼] (최우선)

**06. 잠이 보약이야** (대표 콘텐츠)
- Q: 충분히 잤는데 왜 피곤한가요? / 잠을 못 자면 통증도 심해지나요? / 자다 자꾸 깨는 것도 불면증인가요? / 침·한약으로 수면 관리가 되나요?
- 요지: 수면은 회복의 생리 과정 → 시간이 충분해도 자주 깨면 피로가 남음 → 통증·스트레스·카페인·생활 리듬을 함께 확인 → 한의학적 진찰로 침·한약을 검토하고, 필요하면 수면질환 검사를 권함
- 원장의 언어 ✅ 슬로건: "잠이 보약이야."

**07. 자율신경과 긴장**
- Q: 검사는 정상인데 몸이 늘 긴장돼요 / 스트레스 받으면 소화도 잠도 안 돼요 / 목·어깨가 늘 뻣뻣해요
- 요지: 자율신경은 심박·소화 조절에 관여 → 스트레스·수면 부족이 긴장에 영향 → 발생 시점·생활 리듬·소화를 종합하고, 다른 질환 가능성도 배제하지 않음
- 원장의 언어 ⚪ 재구성: "몸이 긴장을 놓지 못하는 이유부터 함께 살펴보겠습니다."

**08. 호흡과 휴식**
- 요지: 편안하고 느린 호흡(조금 길게 내쉬기)은 일부 사람에게 긴장 완화에 도움 → 무리하게 참지 않기 → 어지러우면 중단
- 원장의 언어 ⚪ 재구성: "하루에 몇 분이라도 몸이 긴장을 내려놓을 시간을 만들어 보세요."

**25. 수면과 식욕의 관계** (칼럼 최우선, '좋은꿈' 이름과 다이어트를 잇는 고리)
- Q: 못 잔 날엔 왜 음식이 당기나요? / 야식을 끊으려면? / 스트레스 받으면 왜 과식하나요?
- 요지: 수면 부족은 식욕 조절에 영향 → 식욕을 의지력 문제로만 보지 않음 → 지속 가능한 습관 찾기
- 원장의 언어 ⚪ 재구성: "식욕을 관리하는 일은 때로 잠을 돌보는 일에서 시작됩니다."

### PART C. 척추·관절·통증 → [진료과목] (최우선)

**09. 척추관절통을 바라보는 관점**
- Q: 목·허리가 왜 반복해서 아픈가요? / MRI에서 디스크가 보이면 꼭 치료해야 하나요?
- 요지: 근육·인대·관절·신경이 관여 → 영상 소견과 통증 정도는 항상 일치하지 않음 → 움직임·신경학적 증상·생활 습관으로 방향을 정함 → 침·추나·약침·물리치료를 선택하거나 추가 검사를 권함
- 원장의 언어 ⚪ 재구성: "통증이 나타나는 곳과 통증에 영향을 주는 곳이 반드시 같지는 않습니다."

**10. 체외충격파** (최우선, 충격파 중심 컨셉과 연결)
- Q: 어떤 치료인가요? / 침과 뭐가 다른가요? / 받을 때 왜 아픈 부위가 더 뚜렷해지나요? / 아플수록 효과가 좋은가요?
- 요지: 기계적 에너지를 몸 밖에서 조직에 전달 → 일부 힘줄·근골격계 질환에서 적용 검토 → 시술 중 압통 반응은 통증 부위 평가의 참고 → 강할수록 좋은 게 아니라 상태에 맞게 강도를 조절
- 진료 흐름(11/24 녹취): 통증 위치·압통 확인 → 주요 치료 부위 기록 → 필요하면 침·초음파 평가와 연계 → 치료 후 상태와 다음 방향 확인
- 원장의 언어 ⚪ 재구성: "충격파를 가하는 것보다 중요한 것은 어느 부위를, 어떤 강도로 치료할 것인지 판단하는 일입니다."
- 메모: "안 아픈 충격파" 컨셉과 문구를 맞추세요. "통증 없음"을 단정하는 표현은 피하는 게 안전합니다.

**11. 추나요법**
- Q: 뼈를 맞추는 치료인가요? / 꼭 소리가 나야 하나요? / 누구나 받을 수 있나요?
- 요지: 한의사의 수기 치료 → 관절 움직임·근육 긴장을 평가해 기법 선택 → 소리가 목표가 아님 → 골절·심한 골다공증·신경학적 이상이 있으면 신중히 판단
- 원장의 언어 ⚪ 재구성: "뼈를 움직이는 것 자체보다 몸이 편안하게 움직일 수 있는 방향을 찾는 것이 중요합니다."

**12. 두개천골추나** (대표 진료, ⚠ 원장 설명 보충 필요)
- Q 후보: 일반 추나와 어떻게 다른가요? / 강한 자극이 부담스러워도 받을 수 있나요? / 머리·목 주변은 어떻게 접근하나요?
- 요지: 머리·척추·천골 주변에 비교적 부드러운 수기 자극 → 목과 연부조직 상태를 보고 적용 검토 → 치매·이명·불면 효과를 단정해 연결하지 않음
