# 네이버 블로그 발행 도구 (공유용 사본)

마크다운 원고를 네이버 블로그 글쓰기 화면에 자동으로 채우고, 원하면 발행까지 누르는 로컬 도구입니다.
Playwright 로 PC에 설치된 구글 크롬을 직접 띄워 조작합니다(크롬 확장 아님).

처음이면 같은 폴더의 **SETUP_FOR_AI.md** 를 먼저 읽으세요(왜 크롬 확장으로는 안 되는지, 탐지 회피 설정, 문제 해결).

## 설치
```bash
npm install
npx playwright install chromium   # 크롬을 못 찾을 때의 예비용
```
구글 크롬과 Node.js 18 이상이 필요합니다.

## 1) 로그인 (처음 1회, 만료 시 다시) — 사람이 직접
```bash
node login.mjs
```
뜬 크롬 창에서 직접 로그인합니다. "로그인 상태 유지"를 켜 두세요. 로그인 정보는 `.chrome-profile/` 에 남습니다(공유·커밋 금지).

## 2) 글 채우기 / 발행
```bash
node post.mjs --file=원고.md --blogId=내아이디 --category="카테고리명"            # 발행 팝업까지 채우고 사람이 발행 클릭
node post.mjs --file=원고.md --blogId=내아이디 --category="카테고리명" --publish  # 발행까지 자동
```
- 원고를 `posts/<이름>.md` 에 두면 `--file=` 대신 `--slug=<이름>` 으로도 됩니다(태그 파일 `tags/<이름>.txt` 는 `--slug` 로 실행할 때만 읽습니다).
- 블로그 아이디는 `--blogId=` 또는 환경변수 `NAVER_BLOG_ID` 로 줍니다.
- 끝나면 터미널이 "Enter 대기"로 멈춥니다. **발행을 확인하기 전에 프로세스를 끄지 마세요**(브라우저가 닫혀 글이 날아갑니다).
- AI가 실행할 때는 입력이 열려 있어야 Enter 대기에서 창이 안 닫힙니다. 예(맥): `(tail -f /dev/null | node post.mjs --file=원고.md --blogId=아이디 --publish > post.log 2>&1 &)` 후 `post.log` 에서 "발행 완료"를 확인하고 프로세스를 끕니다.

### 원고 형식 (마크다운)
```markdown
---
title: 글 제목
tags: [태그1, 태그2]
---

본문 첫 문단입니다.

![사진 설명](사진.jpg)
*사진 아래 작은 캡션(선택)*

## 소제목
- 목록
```
- `##` 소제목은 굵은 큰 글씨, `**굵게**`, `*기울임*` 서식이 유지됩니다.

### 사진
- `images/<원고파일이름>/` 폴더에 사진을 넣습니다(예: 원고가 `여행.md` 면 `images/여행/01.jpg`, `02.jpg`).
- 원고의 `![](…)` 줄 개수 = 폴더 사진 장수이면 **그 자리에** 사진이 들어갑니다(파일 이름 순서 = 원고 순서). 개수가 다르면 글 끝에 모아 올립니다.
- 사진 없이 하려면 `--no-images`.

### 태그
- 기본은 원고의 `tags:`. 더 많이 넣으려면 `tags/<원고파일이름>.txt` 에 한 줄에 하나(최대 30개, `#` 으로 시작하는 줄은 주석).

## 3) 이미 발행한 글 고치기
```bash
node edit.mjs --logNo=<글번호> --slug=<원고이름> --blogId=내아이디
```
원고는 `posts/<원고이름>.md`, 사진은 `images/<원고이름>/`. 본문과 사진을 지우고 원고로 다시 채웁니다. 「수정」 클릭은 사람이 합니다.

## 카테고리 목록 보기
```bash
node category.mjs --list --blogId=내아이디
```

## 주의
- 본인 블로그·본인 글만, 낮은 빈도로. 대량·반복 발행은 네이버 제재 대상입니다.
- 캡차·2차 인증은 사람이 합니다.
- 네이버 화면이 바뀌면 선택자가 깨질 수 있습니다(2026년 11월 기준 동작 확인).
- 원래 회사 홈페이지 저장소 안에서 쓰던 도구라, `--slug=` 옵션과 앱 설치 링크 자동 추가 기능은 이 사본에서는 동작하지 않습니다. 원고는 `posts/` 폴더 또는 `--file=` 로 줍니다.
